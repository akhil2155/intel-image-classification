# Intel Image Classification using Deep Learning

## Project Description
- Developed a Convolutional Neural Network (CNN) pipeline to automate multi-class scene categorization across six diverse landscape environments (Buildings, Forests, Glaciers, Mountains, Seas, and Streets).
- Performed data ingestion, image normalization, automated resizing, and structural dataset shuffling to prevent selection bias and ensure model generalization.
- Trained and evaluated deep learning models using advanced performance metrics and multi-class confusion matrices to isolate class-level errors.
- Built an interactive pipeline utilizing TensorFlow and Keras to convert raw geospatial and structural imagery into actionable, localized feature maps.

## Tech Stack
- **Languages:** Python
- **Frameworks & Deep Learning:** TensorFlow, Keras
- **Data Engineering & Preprocessing:** Scikit-learn, Scikit-image
- **Visualization & Diagnostics:** Seaborn, Matplotlib
